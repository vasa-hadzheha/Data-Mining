This repository contains academic and practical projects focused on data mining techniques for extracting insights from structured datasets. It includes work in both R and Python, covering a wide range of methods such as:

Exploratory Data Analysis (EDA) – uncovering patterns and trends in real-world datasets.

Dimensionality Reduction – using PCA and t-SNE for visualization and feature selection.

Classification & Regression – including decision trees and Random Forests.

Unsupervised Learning – clustering, fuzzy methods, and segmentation.

Predictive Modeling – forecasting and evaluation with proper metrics.

Feature Engineering & Cleaning – using tidyverse, scikit-learn, and custom logic.

Libraries used:

R: tidyverse, ggplot2, cluster, caret, factoextra

Python: pandas, scikit-learn, matplotlib, seaborn

These projects demonstrate the application of core data mining principles on topics such as life expectancy, platform comparisons, and travel-time prediction.
